# IP country

Live visits use trusted Vercel IP country metadata. Historical conversation views can resolve stored IPs locally with geoip-country; no IP is sent to a geolocation API. Unknown and private addresses have no flag. IP location is approximate and can reflect a VPN.

This product includes GeoLite2 Data created by MaxMind, available from https://www.maxmind.com/. The bundled database license and attribution remain distributed with the geoip-country dependency. The pinned country-only data snapshot is updated alongside dependency maintenance.
